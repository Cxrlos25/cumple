# Página de Cumpleaños

Una breve animación  animada creada especialmente para alguien muy especial para mi en su momento

## Como funciona

La animación tiene 3 fases por cada letra:

1. **Fuego artificial** - cada letra viaja desde el centro de la pantalla hacia su posición con una estela de colores
2. **Explosion** - al llegar, explota en fragmentos que caen con gravedad y aparece un circulo que revela la letra
3. **Globo** - la letra se infla como globo y flota hacia arriba hasta salir de pantalla, luego se reinicia

## Tecnologias

- HTML
- CSS
- JavaScript (Canvas API)
